# The Cupboard (Android app)

1. Push this folder to a GitHub repo (branch `main`).
2. Repo Settings > Pages > Source: **GitHub Actions** (one time).
3. Every push builds `TheCupboard.apk`, adds it to Releases, and updates the download page at
   `https://<you>.github.io/<repo>/`.

Edit `www/index.html` to change the app. In the app: Share tab > Backup & restore.
